# Specimen 1: PyTorch Convolutional Neural Network
import torch
import torch.nn as nn

class VisionClassifier(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2, 2),
            nn.Conv2d(32, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2, 2)
        )
        self.classifier = nn.Linear(64 * 8 * 8, num_classes)

    def forward(self, x):
        x = self.features(x)
        return self.classifier(torch.flatten(x, 1))

# Specimen 3: Sentiment Vectorization & Classification
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression

corpus = [
    "The autonomous drone detected obstacle immediately",
    "Sensor telemetry failed due to motor battery drain"
]

vectorizer = TfidfVectorizer(ngram_range=(1, 2))
X = vectorizer.fit_transform(corpus)
model = LogisticRegression()
model.fit(X, [1, 0]) # 1: Operational, 0: Alert

Structured 12-Week Syllabus

12-Week AI & Machine Learning Syllabus

Students transition from data exploratory analysis and scikit-learn models to training convolutional vision classifiers and evaluating model ethics.

PHASE 01

Data Science Foundations & Statistical Feature Space

Weeks 1 to 3 · NumPy matrices, Pandas dataframes, and data normalization

Week 01
Matrix Computations & NumPy

Vector spaces, dot products, multidimensional arrays, and statistical features.

Week 02
Data Cleaning with Pandas

Handling missing values, categorical encoding, feature scaling, and correlation heatmaps.

Week 03
Exploratory Data Analysis

Data distributions, outlier detection, matplotlib visualizations, and train/test splitting.

PHASE 02

Classical Machine Learning & Decision Boundaries

Weeks 4 to 6 · Supervised regression, classification, and model metrics

Week 04
Linear & Logistic Regression

Cost functions, gradient descent optimization, decision thresholds, and house price prediction.

Week 05
Decision Trees & Random Forests

Gini impurity, entropy, ensemble bagging, feature importance, and diagnostic models.

Week 06
Evaluation Metrics & Validation

Confusion matrices, precision vs recall curves, F1-scores, and cross-validation.

PHASE 03

Deep Learning, Neural Layers & Computer Vision

Weeks 7 to 9 · Multi-layer perceptrons, convolutional filters, and PyTorch

Week 07
Neural Architecture & Tensors

Perceptrons, activation functions (ReLU, Sigmoid), forward propagation, and backpropagation.

Week 08
Convolutional Neural Networks (CNNs)

Kernels, stride, pooling layers, feature maps, and classifying handwritten digits (MNIST).

Week 09
Computer Vision Classification

Training image models with webcam feeds, data augmentation, and object recognition.

PHASE 04

Production Deployment & Ethical AI Defense

Weeks 10 to 12 · NLP, model serving via Flask API, and portfolio showcase

Week 10
Natural Language Processing (NLP)

Tokenization, stopword removal, word embeddings, and customer sentiment classifiers.

Week 11
AI Ethics, Bias & Transparency

Algorithmic fairness, dataset bias audits, deepfake detection, and intellectual property.

Week 12
Capstone AI Deployment & Defense

Packaging the trained model behind a live REST API and presenting the project to parents.

Frequently Asked Questions

What age is this course designed for?

AI & Machine Learning is tailored for teenagers aged 12 to 18. Students should have foundational Python knowledge (variables, loops, functions) before enrolling.

What software and libraries are taught?

We teach real Python libraries: NumPy, Pandas, Matplotlib, Scikit-learn, and PyTorch. Classes run in Google Colab or local VS Code notebooks without hardware limits.

Is a high-end GPU required?

No. We utilize cloud-hosted GPU environments such as Google Colab, allowing students on any standard laptop or Chromebook to train deep learning models seamlessly.
