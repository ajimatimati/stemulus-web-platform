Common Traps for this Lesson
Script Runs Before the Page Exists

If the script loads in the head, getElementById returns null. Move the script to the end of body or use defer.

Calling the Function Instead of Passing It

addEventListener('click', run) is right. addEventListener('click', run()) runs it immediately.

Unclosed HTML Containers

Every opened container tag (div, p, section) must have a matching closing tag.

Rule of Two Questions (Zero Touch Typing)

Never take over the student's mouse or keyboard. Ask two progressive questions:

  1. "Look at the line right above the cursor: how does it differ from our example?"
  2. "If the computer reads left-to-right, what character did it encounter first?"
