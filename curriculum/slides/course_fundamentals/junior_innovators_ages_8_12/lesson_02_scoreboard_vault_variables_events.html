Common Traps for this Lesson
Variable Never Set First

Set the starting value before using it. A score that has no start value cannot be increased.

Green Flag Start Trigger

Check that script stacks begin with a start event rather than loose blocks.

Infinite Loop Freezes

Loops with zero delay can freeze the tab. Add a short wait inside forever loops.

Rule of Two Questions (Zero Touch Typing)

Never take over the student's mouse or keyboard. Ask two progressive questions:

  1. "Look at the line right above the cursor: how does it differ from our example?"
  2. "If the computer reads left-to-right, what character did it encounter first?"
