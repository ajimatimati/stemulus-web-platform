What to Look For:
• Loops allow computers to process repetitive data in milliseconds
• Counter variables let code change slightly on every pass
• Break conditions prevent dreaded infinite loops
The Counter Variable

A loop index (i) that counts: 1, 2, 3, 4, 5 on each lap.

The Step Size

Count by 2s or 5s to create repeating geometric patterns.

While vs For

For repeats a fixed number of times; While repeats until a goal is met.

Common Traps for this Lesson
Loop That Never Ends

Check what changes each time round. If nothing changes, the loop has no way to stop.

Unclosed HTML Containers

Every opened container tag (div, p, section) must have a matching closing tag.

CSS Semicolon Omission

Style rules fail silently if a property line lacks a trailing semicolon.

Rule of Two Questions (Zero Touch Typing)

Never take over the student's mouse or keyboard. Ask two progressive questions:

  1. "Look at the line right above the cursor: how does it differ from our example?"
  2. "If the computer reads left-to-right, what character did it encounter first?"
