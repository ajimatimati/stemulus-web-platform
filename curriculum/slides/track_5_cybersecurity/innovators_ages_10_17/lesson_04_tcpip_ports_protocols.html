Packet Capture Inspector
Sample Lab Capture
$ tcpdump -n -c 3 port 80
IP 192.168.1.20.51544 > 192.168.1.1.80: Flags [S], seq 1020, length 0
IP 192.168.1.1.80 > 192.168.1.20.51544: Flags [S.], seq 7788, ack 1021, length 0
IP 192.168.1.20.51544 > 192.168.1.1.80: Flags [.], ack 1, length 0
Command executed successfully Shell: bash
What it means: That is the TCP three-way handshake: SYN, SYN-ACK, ACK. Plain HTTP on port 80 can be read by anyone who captures it.

Which port number is the global standard for secure encrypted web traffic (HTTPS)?
Port 443 is universally designated for encrypted HTTPS traffic, whereas Port 80 is unencrypted HTTP.

Common Traps for this Lesson
Only Capture Your Own Network

Packet capture is practised only on your own lab or approved sample files. Revisit the white-hat rules.

Encryption vs Hashing Confusion

Encryption is two-way (can be decrypted); cryptographic hashing is irreversible one-way.

Plaintext Credentials

Never hardcode passwords or API keys in code snippets or URL query strings.

Rule of Two Questions (Zero Touch Typing)

Never take over the student's mouse or keyboard. Ask two progressive questions:

  1. "Look at the line right above the cursor: how does it differ from our example?"
  2. "If the computer reads left-to-right, what character did it encounter first?"
