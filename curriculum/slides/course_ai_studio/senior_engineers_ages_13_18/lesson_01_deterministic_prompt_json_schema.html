What to Look For:
• Unstructured text cannot be directly parsed by game engines and databases
• JSON schemas establish a contractual interface between the LLM and your code
• Temperature controls entropy: low for schemas, high for creative narrative
System Prompts & Temperature

Temperature = 0.2 for deterministic JSON schemas; 0.9 for creative prose.

Structured Schema Validation

Enforcing typed keys: `item_name: string`, `damage: integer`, `element: enum`.

Game Parser Pipeline

Directly deserializing LLM outputs into native game engine data structures without regex parsing.

Common Traps for this Lesson
One-Line Prompts

Ask for a role, a task, a format and one constraint. Compare the result with the one-line version.

Vague Single-Sentence Prompts

Students write 2-word prompts. Remind them of the 3-part formula: Role, Task, Format Constraints.

AI Hallucination Trust

Model answers must always be fact-checked against official documentation or math tests.

Rule of Two Questions (Zero Touch Typing)

Never take over the student's mouse or keyboard. Ask two progressive questions:

  1. "Look at the line right above the cursor: how does it differ from our example?"
  2. "If the computer reads left-to-right, what character did it encounter first?"
