// Autonomous Sonar Obstacle Avoidance Rover
const int TRIG_PIN = 9;
const int ECHO_PIN = 10;
const int MOTOR_L_PWM = 5;
const int MOTOR_R_PWM = 6;

void setup() {
  Serial.begin(115200);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
}

void loop() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  long duration = pulseIn(ECHO_PIN, HIGH);
  float distanceCM = duration * 0.034 / 2.0;

  if (distanceCM < 20.0) {
    executeAvoidance();
  } else {
    analogWrite(MOTOR_L_PWM, 180);
    analogWrite(MOTOR_R_PWM, 180);
  }
}
// Dual IR Photodiode Course Correction Loop
const int SENSOR_LEFT = A0;
const int SENSOR_RIGHT = A1;
const int THRESHOLD = 550;

void loop() {
  int valLeft = analogRead(SENSOR_LEFT);
  int valRight = analogRead(SENSOR_RIGHT);

  if (valLeft > THRESHOLD && valRight > THRESHOLD) {
    driveForward(200);
  } else if (valLeft <= THRESHOLD) {
    steerRight(160);
  } else if (valRight <= THRESHOLD) {
    steerLeft(160);
  }
}
// 4-Axis Articulated Servo Manipulator
#include <Servo.h>

Servo baseServo;
Servo elbowServo;
Servo wristServo;
Servo clawServo;

void pickupSequence() {
  baseServo.write(90);   // Center azimuth
  elbowServo.write(45);  // Lower arm
  clawServo.write(120);  // Clamp payload
  delay(300);
  elbowServo.write(110); // Lift arm
}

Structured Robotics Engineering Pathway

12-Week Arduino Robotics Syllabus

Students build physical circuit prototypes and write genuine C++ firmware in private 1-on-1 sessions, graduating with multiple working autonomous machines.

PHASE 01

Microcontroller Architecture & Electronic Circuits

Weeks 1 to 3 · Breadboarding, Ohm's Law, digital I/O pins, and first C++ programs

Week 01
The Microcontroller Core

Arduino board architecture, USB communication, flashing firmware, and understanding digital HIGH/LOW states.

Week 02
Breadboard Circuits & Resistors

Ohm's Law, current limits, wiring LEDs in series and parallel, and reading schematic wiring diagrams.

Week 03
Buttons & Digital Debouncing

Pull-up/pull-down resistors, mechanical switch bounce, and software debouncing in C++ conditional loops.

PHASE 02

Sensors, Analog Signals & PWM Actuation

Weeks 4 to 6 · Potentiometers, photocells, ultrasonic sonar, and servo motors

Week 04
Analog-to-Digital Conversion (ADC)

10-bit resolution readings, calibrating light-dependent resistors (LDR), and mapping values with the map() function.

Week 05
Servo Actuation & PWM Signals

Pulse-width modulation, controlling servo shaft angles with precision timing, and engineering articulated joints.

Week 06
Ultrasonic Echolocation Sensors

Calculating distance using sonic pulse round-trip times and building an interactive parking sensor with buzzer feedback.

PHASE 03

Autonomous Mobile Robotics & Motor H-Bridges

Weeks 7 to 9 · DC motors, L298N motor drivers, differential steering, and navigation algorithms

Week 07
DC Motors & H-Bridge Drivers

High-current isolation, controlling speed and rotational direction of dual DC geared motors using L298N drivers.

Week 08
Autonomous Obstacle Avoidance

Mounting sonar onto a scanning servo to look left and right before committing to navigational turns in real space.

Week 09
IR Infrared Line Tracking

Differential course correction using infrared reflectance sensors to follow high-contrast track pathways at speed.

PHASE 04

Complex Integration, Capstone Robot & Showcase

Weeks 10 to 12 · 4-axis robotic arm or hybrid autonomous vehicle defense and certification

Week 10
Multi-Sensor Robot Architecture

Integrating sensory input with multi-motor actuation into a unified state-machine C++ firmware architecture.

Week 11
Hardware Debugging & Optimization

Troubleshooting electrical loose connections, voltage drops, and profiling loop execution cycles using Serial logs.

Week 12
Final Robotic Demonstration & Defense

The student demonstrates their fully operational robot live, presenting their circuit diagrams and firmware code.

Frequently Asked Questions

Do I need to buy any equipment?

No. We can recommend complete Arduino kits that can be ordered directly, or students can begin with virtual circuit simulation in Autodesk Tinkercad before touching physical microcontrollers.

Is prior coding experience needed?

Basic coding experience (like Scratch or Python) is helpful but not mandatory. We teach C++ syntax and embedded electronics concepts step-by-step alongside circuit schematics.

How do we learn robotics online?

We use interactive circuit simulation environments alongside direct overhead webcam video guidance during 1-on-1 sessions. Your mentor reviews wiring connections and code line by line.
