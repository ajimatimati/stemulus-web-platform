How Block Logic Translates to Real Computing

Students do not merely click buttons. They design algorithmic structures, coordinate physics, and variable states that map directly to high-level programming languages.

// Block Structure 1: Maze Movement & Wall Collision
WHEN [Green Flag] clicked:
    go_to(x: -200, y: 150)
    SET [coins_collected] TO 0
    FOREVER:
        IF <key [Right Arrow] pressed?> THEN:
            change_x_by(5)
            IF <touching_color([Wall Navy])?> THEN:
                change_x_by(-5) // Rebound physics
        IF <touching([Goal Portal])?> THEN:
            broadcast([Level Complete])
// Block Structure 2: Gravity Simulation & Velocity Vector
WHEN [Green Flag] clicked:
    SET [y_velocity] TO 0
    FOREVER:
        change_y_by([y_velocity])
        CHANGE [y_velocity] BY -1 // Gravity pull
        IF <touching_color([Ground])?> THEN:
            SET [y_velocity] TO 0
            IF <key [Space] pressed?> THEN:
                SET [y_velocity] TO 12 // Impulse jump
# Bridging: How Scratch Logic Maps Directly to Python
class PlayerSprite:
    def __init__(self):
        self.x, self.y = -200, 150
        self.coins = 0

    def update(self, keys, walls):
        if keys["RIGHT"]:
            self.x += 5
            if self.collides_with(walls):
                self.x -= 5
        print(f"Sprite position: ({self.x}, {self.y})")

Foundational Engineering Pathway

10-Week Scratch Creators Syllabus

Starting from basic sprite controls and progressing to multi-level physics games, students master logical sequencing in private 1-on-1 sessions.

PHASE 01

Coordinate Geometry & Motion Sequencing

Weeks 1 to 3 · Understanding stage axes, directional angles, and loops

Week 01
The Stage & Cartography

X and Y coordinate planes, sprite placement, costume switches, and creating animated walking sequences.

Week 02
Event-Driven Motion

Key press triggers, mouse-pointer tracking, gliding physics, and building an interactive underwater aquarium.

Week 03
Repetition & Loops

Forever loops, repeat counts, pattern drawing with the Pen extension, and geometric spirograph art.

PHASE 02

Sensory Hitboxes, Variables & Conditionals

Weeks 4 to 5 · Decision making and state data storage

Week 04
Conditional Branching

If/then sensory tests, color detection, boundary barriers, and engineering a playable 2D maze game.

Week 05
Variables & Scorekeeping

Creating score counters, health bars, countdown timers, and building an arcade fruit-catching challenge.

PHASE 03

Game Physics, Clones & Message Broadcasts

Weeks 6 to 8 · Multi-sprite communication and realistic mechanics

Week 06
Message Broadcasting

Inter-sprite signaling, stage scene transitions, level-ups, and game-over screens.

Week 07
Cloning & Enemy Waves

Dynamic sprite spawning, random trajectories, memory management, and space-invader style games.

Week 08
Platformer Physics

Simulating gravity, jump velocity, platform collision checks, and scrolling backgrounds.

PHASE 04

Capstone Game Project & Portfolio

Weeks 9 to 10 · Designing and publishing an original game

Week 09
Game Architecture & Sound

Synthesizing audio effects, game balancing, original character art, and 1-on-1 mentor guidance.

Week 10
Playtesting & Community Showcase

Bug fixing, publishing to the Scratch community, and live presentation for parents.
