What to Look For:

• State objects preserve context across player turns and interactions
• Graph nodes make complex narrative logic visually verifiable
The Quest State (Context)

State object storing player inventory, health, NPC trust levels, and quest flags.

State Transition Nodes

States: `QUEST_NOT_STARTED` -> `SEARCHING_RUINS` -> `BOSS_ENGAGED` -> `COMPLETED`.

Transition Predicates

Logic gates determining whether a player is permitted to transition to the next node.

Common Traps for this Lesson
Forgetting to Stage Before Commit

git commit only saves what was added with git add. Check git status after each step.

Vague Single-Sentence Prompts

Students write 2-word prompts. Remind them of the 3-part formula: Role, Task, Format Constraints.

AI Hallucination Trust

Model answers must always be fact-checked against official documentation or math tests.

Rule of Two Questions (Zero Touch Typing)

Never take over the student's mouse or keyboard. Ask two progressive questions:

  1. "Look at the line right above the cursor: how does it differ from our example?"
  2. "If the computer reads left-to-right, what character did it encounter first?"
