Common Traps for this Lesson
Unclosed HTML Containers

Every opened container tag (div, p, section) must have a matching closing tag.

CSS Semicolon Omission

Style rules fail silently if a property line lacks a trailing semicolon.

Quote Mismatches in Attributes

Check for mismatched quotes like class="btn' or missing ending quotes.

Rule of Two Questions (Zero Touch Typing)

Never take over the student's mouse or keyboard. Ask two progressive questions:

  1. "Look at the line right above the cursor: how does it differ from our example?"
  2. "If the computer reads left-to-right, what character did it encounter first?"

Canonical Concept Glossary
Formal vocabulary for Web & Interactive App Engineering

Mastering precise software vocabulary avoids conceptual ambiguity. Define what terms ARE and avoid loose slang:

Request & Response
Definition: Clients send HTTP requests (GET/POST); servers reply with status codes & HTML.
Rule: Avoid: Imprecise jargon or loose synonyms without formal definitions
DOM Tree
Definition: The live in-memory object representation of your parsed HTML document.
Rule: Avoid: 'Website code' (it's the live memory tree, not the file)

Definition: Inspect HTTP headers, response times, and console diagnostics.
