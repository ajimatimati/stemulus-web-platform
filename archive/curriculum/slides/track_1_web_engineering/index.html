Track 1: Web Engineering

Architect the Modern Web: Semantic Layouts, CSS Mastery & Interactive JavaScript

Websites are the digital storefronts, games, and operating systems of the modern world. In Track 1, students build authentic web engineering intuition: understanding how servers transmit packets, structuring bulletproof semantic HTML5 documents, mastering CSS Box Model, Flexbox, and Grid layouts, and breathing life into pages with vanilla JavaScript event listeners and DOM manipulation.
