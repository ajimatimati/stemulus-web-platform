What to Look For:
• Finite State Machines guarantee a robot is in exactly one well-defined behavioral mode at a time.
• Transition guards isolate decision logic to only the events relevant to the active state.
• Watchdog timers and global emergency guards ensure fail-safe physical operation.
Deterministic State Graph

An FSM defines a strict set of mutually exclusive states (IDLE, PATROL, AVOID_OBSTACLE, DOCK_CHARGE, FAULT). The robot can only inhabit ONE state at any instant.

Transition Guards

Arrows connecting states are guarded by boolean conditions: e.g., PATROL transitions to DOCK_CHARGE if and only if battery_pct < 15%.

State Watchdog Timers

What if a robot enters AVOID_OBSTACLE and gets wedged under a chair? A state watchdog timer checks elapsed time in the current state and triggers FAULT recovery if stuck > 5s.

# NASA-Style Deterministic Finite State Machine (FSM) class RoverFSM: def __init__(self): self.state = "IDLE" self.state_time_s = 0.0 def step(self, dt, start_cmd, dist_cm, battery_pct): self.state_time_s += dt prev = self.state # Global highest-priority safety guard if battery_pct < 15 and self.state != "FAULT": self.state = "DOCK_CHARGE" elif self.state == "IDLE": if start_cmd: self.state = "PATROL" elif self.state == "PATROL": if dist_cm < 25.0: self.state = "AVOID_OBSTACLE" elif self.state == "AVOID_OBSTACLE": if dist_cm >= 40.0: self.state = "PATROL" elif self.state_time_s > 5.0: # Watchdog timeout! self.state = "FAULT" if self.state != prev: self.state_time_s = 0.0 print(f"[FSM TRANSITION] {prev} ---> {self.state}") else: print(f"[FSM ACTIVE] State: {self.state} (t={self.state_time_s:.1f}s)") fsm = RoverFSM() for start, dist, bat in [(True, 80, 90), (True, 18, 88), (True, 50, 85), (True, 50, 12)]: fsm.step(1.0, start, dist, bat)

Common Traps for this Lesson
Missing Common Ground (GND)

When using a separate battery pack for motors or servos, always connect battery GND to microcontroller GND so PWM signals have a 0V reference.

Powering Servos from 3.3V Logic Pin

Motors draw high stall current that causes CPU brownout resets. Power actuators from a dedicated supply rail.

Floating Input Pins

Unconnected digital inputs pick up static noise. Enable internal Pin.PULL_UP or Pin.PULL_DOWN resistors.

Rule of Two Questions (Zero Touch Typing)

Never take over the student's mouse or keyboard. Ask two progressive questions:

  1. "Look at the line right above the cursor: how does it differ from our example?"
  2. "If the computer reads left-to-right, what character did it encounter first?"
