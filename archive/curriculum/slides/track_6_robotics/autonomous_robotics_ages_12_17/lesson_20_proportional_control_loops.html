The Big Idea: Open-Loop vs. Closed-Loop Control, Setpoints, Error Signals & Proportional Gain (Kp)

What to Look For:
• Closed-loop systems use sensor feedback to continuously minimize Setpoint error.
• Proportional control scales actuator output linearly with error magnitude.
• Excessive proportional gain (Kp) introduces overshoot and sustained oscillations.
Open-Loop vs. Closed-Loop

Open-loop commands motors blindly without checking the result. Closed-loop continuously reads sensor feedback, compares it to the target Setpoint, and adjusts actuator effort in real time.

The Error Signal: e(t)

Error = Setpoint - Measured Value. If your robot wants to stay 30cm from a wall (Setpoint = 30) and reads 20cm, the Error is +10cm. If it reads 30cm, Error is 0!

Proportional Gain (Kp)

Control Output = Kp * Error. A small error produces a gentle steering correction; a large error produces a strong correction! Tuning Kp balances responsiveness against oscillation.

# Closed-Loop Proportional (P) Distance Cruise Controller TARGET_DIST_CM = 30.0 KP = 3.5 # Proportional Gain constant BASE_SPEED = 50 def p_controller_step(measured_dist_cm): # 1. Compute Error: e(t) = Setpoint - Process Variable error = measured_dist_cm - TARGET_DIST_CM # 2. Compute Proportional Control Effort: u(t) = Kp * e(t) control_output = KP * error # 3. Clamp motor command to safe bounds (-100% to +100%) motor_cmd = max(-100, min(100, int(control_output))) print(f"Dist: {measured_dist_cm:5.1f}cm | Error: {error:+5.1f}cm | Motor PWM: {motor_cmd:+4d}%") return motor_cmd # Simulate rover approaching a target vehicle from 55cm down to 25cm for dist in [55.0, 42.0, 34.0, 30.0, 26.0]: p_controller_step(dist)

Common Traps for this Lesson
Loop That Never Ends

Check what changes each time round. If nothing changes, the loop has no way to stop.

Missing Common Ground (GND)

When using a separate battery pack for motors or servos, always connect battery GND to microcontroller GND so PWM signals have a 0V reference.

Floating Input Pins

Unconnected digital inputs pick up static noise. Enable internal Pin.PULL_UP or Pin.PULL_DOWN resistors.

Rule of Two Questions (Zero Touch Typing)

Never take over the student's mouse or keyboard. Ask two progressive questions:

  1. "Look at the line right above the cursor: how does it differ from our example?"
  2. "If the computer reads left-to-right, what character did it encounter first?"
