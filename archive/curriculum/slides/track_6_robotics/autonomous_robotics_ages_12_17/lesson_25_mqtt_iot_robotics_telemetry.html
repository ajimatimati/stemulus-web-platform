What to Look For:
• MQTT decouples message publishers from subscribers via a central topic broker.
• JSON provides a human-readable, language-independent schema for sensor payloads.
• Heartbeat watchdogs and Last Will messages protect physical hardware during network drops.
MQTT Lightweight Messaging

HTTP web requests have huge text headers and high latency. MQTT (Message Queuing Telemetry Transport) uses tiny 2-byte binary headers designed specifically for real-time robotics and IoT.

Structured JSON Telemetry

Instead of fragile raw strings, robots package state into JSON objects: {"rover_id": "R1", "state": "PATROL", "bat": 92, "pose": [120, 45]}.

Dead-Man's Switch Heartbeat

What if Wi-Fi drops while a remote pilot is holding down the 'Forward' button? A 500ms Heartbeat Watchdog automatically halts the motors if telemetry packets stop arriving!

If a robot receives a 'DRIVE_FORWARD' packet and then loses Wi-Fi connection before receiving the 'STOP' packet, it would drive blindly into walls unless a heartbeat timeout halts the actuators.

Common Traps for this Lesson
Missing Common Ground (GND)

When using a separate battery pack for motors or servos, always connect battery GND to microcontroller GND so PWM signals have a 0V reference.

Powering Servos from 3.3V Logic Pin

Motors draw high stall current that causes CPU brownout resets. Power actuators from a dedicated supply rail.

Floating Input Pins

Unconnected digital inputs pick up static noise. Enable internal Pin.PULL_UP or Pin.PULL_DOWN resistors.

Rule of Two Questions (Zero Touch Typing)

Never take over the student's mouse or keyboard. Ask two progressive questions:

  1. "Look at the line right above the cursor: how does it differ from our example?"
  2. "If the computer reads left-to-right, what character did it encounter first?"
