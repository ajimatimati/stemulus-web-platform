Track 3: UI/UX and Game Design

Design for Humans, Build for Players: Wireframing, Game Mechanics & Phaser

Great software starts on the design board. Track 3 bridges user empathy and game physics. Learners conduct user research, sketch grayscale wireframes, design atomic component systems in Figma, and transition into game design with sprites, particle effects, collision physics, and 60 FPS game loops in Phaser.
