/* Modern CSS Grid & Custom Properties */
.planet-card {
  display: grid;
  gap: 1rem;
  padding: 1.5rem;
  background: #0F172A;
  border: 1px solid rgba(255, 255, 255, 0.1);
  border-radius: 8px;
  transition: transform 0.2s ease;
}
.planet-card:hover {
  transform: translateY(-2px);
  border-color: #F4600C;
}

  btn.textContent = "Probe Launched!";

Structured Frontend Pathway

10-Week Web Wizards Syllabus

Students build, style, and deploy 4 original websites in private 1-on-1 sessions, learning industry-standard tools and web architecture.

PHASE 01

Semantic Markup & Document Architecture

Weeks 1 to 3 · HTML5 foundations, hyperlinks, media embeds, and forms

Week 01
The Web Ecosystem & HTML5

How the web works, servers, browsers. Writing headings, paragraphs, lists, and semantic container tags.

Week 02
Hyperlinks, Media & Tables

Absolute vs relative paths, embedding high-res imagery, audio elements, and structured data tables.

Week 03
Forms & Project 1 Launch

Input fields, radio buttons, dropdowns, and building their first multi-page Fan Portal website.

PHASE 02

Modern CSS3, Typography & Color Systems

Weeks 4 to 5 · The Box Model, custom fonts, and styling precision

Week 04
The Box Model & Spacing

Margins, padding, borders, content box calculations, and avoiding layout overflow.

Week 05
Typography & Modern Palette

Google Fonts integration, line heights, letter tracking, hex/hsl color models, and subtle hover transitions.

PHASE 03

Responsive Layouts, Flexbox & CSS Grid

Weeks 6 to 8 · Modern layout engines for mobile, tablet, and desktop

Week 06
Flexbox Alignment Systems

Justify-content, align-items, flex-direction, and engineering modern navigation bars and card decks.

Week 07
CSS Grid & Media Queries

Grid template columns, fractional units, gap spacing, and fluid responsive breakpoints.

Week 08
Project 2 & 3: Pet Rescue & Store

Building a fully responsive multi-card product showcase and animal sanctuary adoption gallery.

PHASE 04

JavaScript DOM & Live Portfolio Deployment

Weeks 9 to 10 · Adding interactivity, custom domains, and live hosting

Week 09
JavaScript DOM Manipulation

Event listeners, dynamic dark mode toggles, interactive modals, and form validation.

Week 10
Git, GitHub & Live Hosting

Publishing sites live to Netlify/GitHub Pages with custom URLs to share with family and admissions boards.

Frequently Asked Questions

Is this the same as Scratch or coding games?

No! HTML/CSS is actual coding | the same languages professional web developers use. Unlike Scratch which uses blocks, students write actual code. This is a great next step after Scratch, or a perfect first text-based coding experience.

Will their websites actually be online?

Yes! By the end of the program, students will have websites published on the live internet using free hosting. They'll have URLs they can share with family and friends | like mychild.github.io/mysite!

What computer is needed?

Any laptop or desktop computer with a web browser works! For in-person classes, we provide all equipment. For online classes, students need Chrome, Firefox, or Edge and we'll guide them through the free tools we use.

What comes after this program?

After mastering HTML/CSS, students can progress to our Full-Stack Web Development program which adds JavaScript and server-side programming. They'll go from static pages to fully interactive web apps!
