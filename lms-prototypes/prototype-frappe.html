Mastering List Indexing and Zero-Based Slicing in Python

In this module, you will learn how computers count starting from index zero, how to extract sub-lists using colon slicing, and how to avoid the common IndexError bug.

Think of a Python list like a series of lockers in school. Every locker has a number on it, but unlike real schools that start numbering from 1, Python programmers always start counting at index 0.

💡
Key Mental Model In Python, the first item is at index 0, the second item is at index 1, and the last item can always be accessed with negative indexing [-1]!

1. Interactive Code Example

Observe the syntax below for our inventory of spaceship tools:

spaceship_inventory.py 
# Define our roster of spaceship equipment
tools = ["Laser Drill", "Solar Battery", "Oxygen Tank", "Radar Beacon"]

# 1. Access the first element (index 0)
print(tools[0])   # Output: Laser Drill

# 2. Access the last element (negative indexing)
print(tools[-1])  # Output: Radar Beacon

# 3. Slice from index 1 up to (but not including) index 3
primary_pack = tools[1:3]
print(primary_pack)  # Output: ['Solar Battery', 'Oxygen Tank']

⚡ Knowledge Checkpoint

What will be printed if you execute tools[1] from the list above?
