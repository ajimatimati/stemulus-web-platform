Tutor & Parent Implementation Best Practices

1. The Three-Moment Lesson Flow (45–60 Minutes):   • Explore (10 Mins): Open the completed project link, let the student play, and ask 'What happens when you click? What code blocks do you think make that happen?'   • Build (25 Mins): Start from a clean Scratch project. Follow the progressive block sequence step-by-step together.   • Remix & Shine (15 Mins): Ask the student to customize one thing (e.g., change the sound, change the animal costume, or add a bonus score rule).2. Zero External Assets Rule:   Every project in this curated pathway uses 100% built-in Scratch library sprites and backdrops. This guarantees:   • Instant loading with zero 404 broken image bugs.   • Children can easily replicate every asset inside Scratch without hunting for files on their computer.   • Safe, kid-friendly vector graphics that scale cleanly at full screen.3. Mastery Pacing Recommendations:   • Ages 5–7: Complete 1 to 2 projects per week across Levels 1–3.   • Ages 7–9: Progress smoothly through Levels 3–6.   • Ages 9–12: Tackle Levels 6–8, culminating in the 3D Subway Surfers runner capstone.
