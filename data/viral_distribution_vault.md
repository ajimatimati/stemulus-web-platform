### Post 2: r/learnprogramming (How to Transition Kids from Scratch to Python)
> **Title:** Lessons from teaching hundreds of kids: The exact bridge from visual blocks to text-based Python.
> 
> **Body:**  
> The biggest drop-off in youth programming happens between block coding (Scratch) and text coding (Python). Kids get frustrated by indentation errors and missing colons.
> 
> Here is the exact 3-step bridge we use at STEMulus:
> 1. Keep the output visual: Never start a 10-year-old with terminal input() commands. Use Python Turtle graphics or simple Pygame surfaces so their code immediately draws visual shapes.
> 2. Direct syntax mapping: Show them how a Scratch 'forever' block is literally 'while True:', and an 'if touching sprite' is conditional boolean logic.
> 3. Short feedback loops: 10 lines of code max per micro-project before running.
> 
> If you have a child aged 10 to 17 ready to transition to real Python, here is our project curriculum: https://stemuluskidstech.com/python-coding-classes-for-teens.html
